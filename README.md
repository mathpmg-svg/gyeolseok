# 결석 · 보강 관리

학원과 과외 수업의 결석을 기록하고, 각 결석에 보강일을 연결해 관리하는 **웹앱**입니다.<br>
**설치가 필요 없고** 주소만 열면 안드로이드 · 아이폰 · PC 어디서나 동작합니다.

**바로 쓰기 → https://mathpmg-svg.github.io/gyeolseok/**



결석 자체를 적어두는 건 어렵지 않습니다. <br>
어려운 건 **어느 결석이 아직 보강되지 않았는지**체크하는 일입니다. <br><br>
종이 달력만 적어두면 <br>
보강을 잡았는지 잡지 않았는지, 몇시에 잡았는지<br>
언제 결석한 수업의 보강인지 매번 되짚어야 합니다.

이 앱은 결석 한 건에 보강일을 연결하고, 그 상태를 색으로 구분합니다.

| 표시 | 뜻 |
|---|---|
| 빨강 | 결석했는데 보강일이 아직 없음 |
| 검정 + 취소선 | 보강일이 잡힌 결석 (처리 끝남) |
| 파랑 | 보강하는 날 |
| 회색 + 취소선 | 차감 처리 (보강 없이 마무리) |

**달력에서 빨간 것만 없애면 그 달 정리가 끝납니다.**

---

## 기능

- 달력에서 눌러 결석 등록, 여러 날 연속 등록
- 결석 ↔ 보강일 연결, 보강 시간 지정 (오전·오후 휠, 10분 단위)
- 보강 없이 마무리하는 차감 처리
- 학생별 월간 요약과 CSV 내보내기
- 달력 표시 방식 선택 (도장만 / 이름만 / 도장+이름)
- 백업 · 복구 (파일, 또는 글자 복사·붙여넣기)
- 홈 화면에 추가해 앱처럼 사용, 오프라인 동작

기록은 **각자의 개인 단말기 안에만** 저장됩니다. 서버로 전송되지 않습니다.
