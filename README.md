# 결석 · 보강 관리

학원과 과외 수업의 결석을 기록하고, 각 결석에 보강일을 연결해 관리하는 웹앱입니다.
설치가 필요 없고 주소만 열면 안드로이드 · 아이폰 · PC 어디서나 동작합니다.

**바로 쓰기 → https://아이디.github.io/저장소이름/**

> 위 주소는 GitHub Pages를 켠 뒤 실제 주소로 바꿔 주세요.

---

## 무엇을 해결하나

결석 자체를 적어두는 건 어렵지 않습니다. 어려운 건 **어느 결석이 아직 보강되지 않았는지**
추적하는 일입니다. 달력에 결석만 적어두면 보강을 잡았는지 매번 되짚어야 합니다.

이 앱은 결석 한 건에 보강일을 연결하고, 그 상태를 색으로 구분합니다.

| 표시 | 뜻 |
|---|---|
| 빨강 | 결석했는데 보강일이 아직 없음 |
| 검정 + 취소선 | 보강일이 잡힌 결석 (처리 끝남) |
| 파랑 | 보강하는 날 |
| 회색 + 취소선 | 차감 처리 (보강 없이 마무리) |

**달력에서 빨간 것만 없애면 그 달 정리가 끝납니다.**

---

## 기능

- 달력에서 눌러 결석 등록, 여러 날 연속 등록
- 결석 ↔ 보강일 연결, 보강 시간 지정 (오전·오후 휠, 10분 단위)
- 보강 없이 마무리하는 차감 처리
- 학생별 월간 요약과 CSV 내보내기
- 달력 표시 방식 선택 (도장만 / 이름만 / 도장+이름)
- 백업 · 복구 (파일, 또는 글자 복사·붙여넣기)
- 홈 화면에 추가해 앱처럼 사용, 오프라인 동작

기록은 **각자의 브라우저 안에만** 저장됩니다. 서버로 전송되지 않습니다.

## 기술 구조

의존성 없는 순수 HTML · CSS · JavaScript입니다. 빌드 과정이 없습니다.

```
index.html            화면 구조
app.css               스타일
app.js                동작 전부
manifest.webmanifest  홈 화면 추가용 정보
sw.js                 오프라인 캐시 (서비스 워커)
favicon.ico           브라우저 탭 아이콘
favicon-32.png        브라우저 탭 아이콘 (고해상도)
icon-192.png          홈 화면 아이콘
icon-512.png          홈 화면 아이콘 (큰 크기)
apple-touch-icon.png  아이폰 홈 화면 아이콘
```

파일이 모두 같은 자리에 있고 하위 폴더가 없습니다.
**10개를 빠짐없이 올려야 합니다.** png 5개를 빠뜨리기 쉽습니다.

데이터는 `localStorage` 에 키 하나(`attendance.v1`)로 저장됩니다.

## GitHub Pages로 배포하기

1. 이 저장소에 파일 10개를 올립니다 (`Add file` → `Upload files`)
2. `Settings` → `Pages` 로 이동
3. Source 는 `Deploy from a branch`, Branch 는 `main` / `(root)` 선택 후 `Save`
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다

### 올린 뒤 확인

주소 뒤에 `/icon-192.png` 를 붙여 열어보세요.
검은 배경에 빨간 원과 파란 원이 그려진 아이콘이 보이면 파일이 모두 올라간 것입니다.
404가 뜨면 png 파일이 빠진 것이니 다시 올리세요.

---

## 파일을 고쳤는데 반영이 안 될 때

서비스 워커가 이전 파일을 캐시하고 있어서입니다.
`sw.js` 첫 부분의 `CACHE` 값을 올린 뒤 (예: `attendance-v10` → `attendance-v11`) 다시 올리세요.

홈 화면에 추가해 쓰는 중이라면 앱을 완전히 종료했다 다시 열어야 새 버전이 잡힙니다.

## 손볼 만한 곳

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 색 | `app.css` 맨 위 `--red`, `--blue` |
| 자주 쓰는 시간 버튼 | `app.js` 의 `'14:00', '15:00', …` 배열 |
| 시간 휠의 분 단위 | `app.js` `timeWheel` 안의 `minList` |
| 달력 한 칸에 보이는 인원 | `app.js` `fillCell` 안의 `LIMIT` |

## 주의할 점

- 기록은 브라우저에만 있습니다. 캐시를 지우거나 기기를 바꾸면 사라지니
  `설정` 탭에서 가끔 백업을 받아 두세요.
- 카카오톡 등 앱 안의 브라우저는 파일 내려받기가 저장되지 않습니다.
  이런 환경에서는 `설정` 탭에 안내가 뜨고, **글자로 백업**을 쓰면 됩니다.
- 기기 간 자동 동기화는 없습니다.
